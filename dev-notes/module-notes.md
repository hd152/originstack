# Module notes (full per-module history)

> Moved verbatim from CLAUDE.md on 2026-10-07 to keep that file small. This is history and measurement narrative, not current instructions; where it disagrees with the code or CLAUDE.md, the code wins. Since this was written the 2026-10 cleanup removed, among others: Python `drizzle_combine`/`_lanczos_resample_frame`, `registration.compute_patch_quality_map`/`patch_scores_to_map`/`apply_shift`, `denoising.reduce_stars`, `debayer.remove_hot_pixels_rgb`, `color_calibrate.synthetic_channel_flux`, `banding.banding_strength`, `sky_model.remove_physical_sky`/`moon_illuminated_fraction`, `ui_events.restretch`/`preview_jpeg` and the retained float16 preview source, `PreviewCanvas.replace_pixels`, `io_*.is_*_file`, `frame_store` `release()`, `tools/benchmark.py`, `tools/reprocess_bg.py`; Rust `online_sigma_clip_combine`, `white_balance_apply_inplace`, the old `patch_weighted_sigma_combine` (only `_fast` remains), f64 `proper_coadd_accum`, the `ORIGINSTACK_LANCZOS_EXACT` switch; `row_parallel`/`row_parallel_pair` merged; transient triage (tract) is behind the off-by-default Cargo feature `triage`.

The pipeline is split across `src/` modules. [originstack.py](originstack.py) is a thin entry-point shim that re-exports all public symbols. Tests import directly from `originstack`. [desktop_app.py](desktop_app.py) is a second, equally thin root shim for the desktop app (`from src.desktop_app import main`; see `src/desktop_app.py` and `src/desktop_control.py` below). | [src/background.py](src/background.py) | Mesh-based sky extraction, DBE, residual removal. **With a caller exclusion mask (galaxy/comet mode) the 'diffuse emission' rule in `_build_emission_mask` is off** (`diffuse=False`): it masks anything 1 smoothed-border sigma above sky, which on a galaxy field is residual gradient (27% of Sunflower), not nebulosity, and the target is already protected. **Three smooth-field blurs use `gaussian_filter_ds(..., ds_threshold=8)`** (mesh spline smooth in `extract_background`, `_fit_background_surface`, the exclusion-mask feather in `remove_sky_residual`), and `multiscale_local_contrast`'s base layers go through `gaussian_filter_ds` (only its 40 px scale downsamples): post-processed output moves 0.05 ADU rms against 40-54 ADU pixel noise, Phase 4 cold 25.0 -> 21.7 s on Sunflower. **Profile while nothing else runs**: a first profile taken alongside a 16-worker stack attributed 27 s to these blurs; uncontended they were ~3 s. What is left is spread thin (wavelet 2.2 s, local contrast 2.2 s, preview 1.2 s, edge bands 1.2 s, astropy `sigma_clipped_stats` ~1.5 s) -- no per-pixel arithmetic worth fusing natively; the big lever for iterating is the `--from-stack` early-step cache (22 -> 8 s). **DBE re-admits gradient patches** (`_admit_gradient_patches`): the sampler drops any patch brighter than the *luminance-based* `sky_ref + 2*sky_std`, so in the strongest channel it dropped most patches and all the edge ones (measured: R 165 patches accepted vs ~715 for G/B; R edge excess +66..+114 ADU survived DBE untouched while G/B were removed completely). It now fits a 2nd/3rd-order polynomial to the accepted patches, admits candidates within 1 sky-sigma of it, refits and repeats (<= 8 rounds), so the model grows outward along a smooth gradient and stops at anything steeper; candidates come from the same sampler with the brightness cut off, so the emission mask and variance/entropy filters still apply. After the fix every edge is within +-3 ADU and the galaxy disk is unchanged or slightly brighter over sky (64.8 -> 70.0). This -- not a narrow strip -- was the coloured band along the JPG's bottom edge. `remove_edge_bands` (step 15a) stays as a partial backstop. When a caller supplies an `exclusion_mask` (`--galaxy-mode`/`--comet-mode`), `_dbe_prepare_emission_mask` first runs `_flatten_edge_glow`: components of the above-sky region larger than 2% of the frame whose smoothed peak lies in the 5% border band are a gradient cut off by the sensor edge (light pollution, a lamp, moonlight toward a corner), not an object, so they are set to sky before the emission detection passes and DBE models them as background. Without an exclusion mask the nebula-protecting default is unchanged (a nebula's brightest part can sit at an edge). Found on a real low-altitude Whirlpool session where a corner glow survived into the output. **`_build_emission_mask`'s compact-source dilation is a distance-transform threshold, not `scipy.ndimage.binary_dilation`**: dilation by a disk of radius r is exactly "within Euclidean distance r of a True pixel" (`ndimage.distance_transform_edt(1 - src_binary) <= r`, verified bit-exact against `binary_dilation(src_binary, structure=disk)`), and unlike scipy's generic morphology machinery this is near-O(H*W) regardless of mask shape. Found by profiling a real stack: scattered-mask synthetic timings looked fine (sub-second either way), but the actual case -- one large *contiguous* bright source (a real galaxy/comet core, not scattered stars) -- measured 16.2s for `binary_dilation` at r=40 on a full-res frame vs 0.37s for the distance-transform route; the profiled run's 2 calls cost 13.6s combined before the fix. **`gaussian_filter_ds`'s large-sigma upsample is bilinear (`order=1`), not cubic (`order=3`)**: profiling the same run found its `affine_transform` upsample step costing 3.5s across 10 calls; cubic's extra curvature term buys nothing on a grid that just came out of this same function's own huge Gaussian blur (measured order=1 vs order=3 mean/max diff 0.001/0.010 against a field std of ~0.75 on realistically-smoothed input) -- ~3x faster per call (0.336 -> 0.111s at ds=4 on a full-res field) |
| [src/denoising.py](src/denoising.py) | Curvelet-style wavelet (`directional_wavelet_denoise`, the default primary denoiser), ACDNR, bilateral, anisotropic diffusion, star reduction, local contrast. `--variance-stabilize` applies a generalized Anscombe transform to the luma plane before wavelet thresholding, inverting it after -- makes BayesShrink's single per-subband noise estimate closer to valid everywhere, not just near the sky background level, since shot noise on bright pixels is Poisson not Gaussian; gain/read-noise are self-estimated from the image's own local mean-variance relationship, not sensor specs. `--denoiser curvelet` (`directional_wavelet_denoise`) is curvelet/shearlet-*inspired* (not an actual ridgelet/shearlet transform): locally reduces the BayesShrink threshold wherever a structure-tensor coherence map (`_structure_tensor_coherence`) detects elongated structure (filaments, galaxy arms), protecting it from thresholding more than an isotropic per-subband threshold would; **`--denoiser wavelet` is the one name** (`curvelet` is a hidden-in-spirit alias, normalised to `wavelet` in `parse_args`); how strongly structure is protected is its own option, `--wavelet-protect 0-1` (dest `directional_protect_strength`, default 0.6, 0 = plain BayesShrink; counts as explicit only when passed). Before 2026-09 `--denoiser wavelet` meant *protection forced to 0* -- old command lines using it now get 0.6; spell the old behaviour `--denoiser wavelet --wavelet-protect 0`. The post-processing step is skippable as `--skip-step wavelet` or `curvelet`. **Removed 2026-09 after `tools/bench_denoise_quality.py`** (ground-truth synthetic scenes, correlated noise matched to real stacks): NLM (halved star peak brightness, 11x the input error inside star cores, 17 s/MP), BM3D (best quality but slow and licence-encumbered; its pure-scipy fallback was worse than the pip package), MMT (erased ~93% of fine structure at its default strength), the non-adaptive `wavelet_denoise` + `--denoise-strength`/`--denoise-strength-calibrate` + the Noise2Self calibration module (only served that path), and `adaptive_wavelet_denoise` (identical to curvelet at protect 0). Old `--denoiser nlm/mmt/bm3d` values now error; `--denoiser wavelet` still works. **`reduce_chroma_noise` must not clip negatives**: it runs right after DBE, which centres the sky on zero, and the sky pedestal that keeps noise positive is applied later. A `np.clip(result, 0, None)` there half-wave-rectified the sky (exactly 50% zeros + positive spikes) and, because the pedestal is sized from the sky MAD, that MAD then read 5 ADU against a true ~100 (pedestal +39 instead of +738) -- the stretch rendered the surviving spikes as a field of white dots on a very low-SNR stack (real Whirlpool session, SNR ~1.7/sub) ([tests/test_corner_glow_and_thin_catalog.py](tests/test_corner_glow_and_thin_catalog.py)) |

| [src/proper_coadd.py](src/proper_coadd.py) | Proper image coaddition (Zackay & Ofek 2017), **on by default since 2026-10** (`--no-proper-coadd`, a single store_false action). After the normal combine, while the aligned stack still exists, it recombines the same frames weighting each *spatial frequency* by the frame's own PSF, transparency and noise: `R = sum (F_j/s_j^2) conj(P_j) M_j / sqrt(sum (F_j^2/s_j^2)|P_j|^2)`, returned as `R / sqrt(sum F_j^2/s_j^2)` -- output MTF is the weighted RMS of the frame MTFs (never below their weighted mean), and at zero frequency it is exactly the weighted mean of `M_j/F_j`, so flux does not depend on the PSF model. Per frame: an elliptical Moffat fitted jointly to ~30 bright isolated stars at the reference stack's centroids (stamps only, per-star amplitude/background solved linearly); **parametrised by FWHM, not alpha** (near the Gaussian limit alpha and beta trade off along a ridge -- the Omega Nebula stack fitted alpha 10-12 px at beta 14 for a 4.5 px FWHM, and an alpha bound rejected every frame); beta held to (1.5, 20). Transparency F_j = each star's flux over its median across frames, median over stars -- **not** against the reference stack's fit: that stack blends frames of different seeing, is no Moffat, and its model flux was ~2% off, straight into the output scale. The output is on the **median frame's flux scale**. Star fluxes for F_j are **aperture sums over the 29x29 stamp less the fitted background, not the model integral**: a smooth model fitted to a *trailed* star grows heavy wings, and its integral read 2x the true flux on seven trailed frames of the Omega session (a periodic mount move every ~15 frames; headers identical), which through `w = F^2/s^2` weighted the worst frames 4x and cost ~2% noise there. Noise s_j: lag-4 MAD per channel on every 4th row. Outliers are replaced against the normal stack first (`k=5`, signal term 0.15 as `cfa_drizzle`). Native `proper_coadd_prep` (reject + sky-subtract + write the padded FFT buffers, bit-identical to `_prep_numpy`) and `proper_coadd_accum` (fused f64 accumulate), crate 0.42.0; one FFT per thread (pocketfft's `workers` did not parallelise these: 4 planes 144 ms with any setting, 47 ms in 4 threads). **Measured vs the default stack (shared-star FWHM / flux-matched noise R,G,B):** Sunflower 0.980 / 0.92,0.88,0.92; Sculptor (531 frames) 0.974 / 0.99,0.99,0.99; Omega 0.987 / 1.00,1.00,1.00 -- sharper on all three at no noise cost (Omega was 1.03,1.01,1.01 before the aperture-flux fix). Cost +20 s (Sunflower) to +37 s (Sculptor). **Against Siril** (`tools/bench_vs_siril.py`, which now takes `--os-args=...` -- the `=` is needed, a value starting with `--` is otherwise read as a flag -- and `--reuse-siril`): shared-star width OS/Siril, default -> proper coadd: Sunflower 1.011 -> 0.989, Omega 0.995 -> 0.980, Sculptor 0.929 -> 0.903; noise vs Siril Sunflower 1.09/0.92/1.05 -> 1.02/0.83/0.97, Omega and Sculptor unchanged (0.92/1.04/1.06, 1.22/0.99/1.32). Run times on the day moved by up to a third between identical runs (both tools), so speed was not re-established. Falls back to the normal stack (with a message) when the PSF cannot be measured. |
| [src/cfa_drizzle.py](src/cfa_drizzle.py) | Bayer-aware drizzle (`--cfa-drizzle`, opt-in). After the normal stack is built, recombines every frame's *measured* colour samples (never the debayer-interpolated ones) onto the output grid as square area-overlap drops (`pixfrac * scale` output px, through `_drizzle_matrix`). **No Phase 1 change**: Malvar leaves each channel's own raw sample untouched in `mem_rgb`, so the measured lattice is recoverable from `args._session_bayer` alone -- hence `--debayer-method malvar` only (bilinear does *not* keep the raw sample; verified). Per-sample rejection against the normal stack as reference, with tolerance `4*sqrt(frame_noise^2 + (0.15*signal)^2)` -- the signal term is load-bearing, a plain sigma clip clips genuine star flanks because seeing/transparency move star peaks ~15% between frames; the reference is looked up **bilinearly** (nearest-pixel lookup rejected real samples on steep flanks). Frames weighted by inverse noise variance; blends back to the reference where lattice coverage is < 70% of a full one. Synthetic benchmark (120 dithered frames): star-core error -34%, chroma error -8%, but per-pixel background noise +37% (no interpolation smoothing) -- a trade, not a free win, and the gain grows with frame count (about break-even at 40). **Real-data verdict (Fireworks Galaxy, 148 frames, FWHM 4.9 px -- well sampled): luma noise -13%, chroma noise +110% (R-G 32->70), star sharpness -5%. Speed: the numpy splat took 407 s on 148 frames (six full-size `bincount` passes per neighbour tap per channel); the native `cfa_drizzle_frame` kernel takes 26 s (15.7x), bit-identical to the numpy path on identical input (translation and rotation to 30 deg; `tests/test_native.py`). The simulation's star-core gain does not appear because a well-sampled PSF has little debayer interpolation error to remove; expect a benefit only on undersampled data (FWHM under ~2.5 px).
