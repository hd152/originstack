隐私政策

本网站和 OriginStack 应用会收集你的哪些信息、为什么收集，以及如何选择退出。最后更新：2026 年 10 月 7 日。

网站运营者

originstack.site 是免费、开源的天文摄影程序 OriginStack 的网站，由 Tom Davenport 运营。如对本政策或你的数据有任何疑问，请在 GitHub 上提交 issue。

访问统计：GoatCounter

本网站使用 GoatCounter 统计访问量，以了解哪些页面被阅读、哪些下载被使用。GoatCounter 不设置 Cookie，也不会跨网站跟踪你。对于每次页面浏览，它会记录页面、来源网站、你的浏览器、操作系统和屏幕尺寸，以及根据你的 IP 地址推断出的国家/地区。它不会存储你的 IP 地址。为了统计独立访问，它会保留一个短期哈希值，时长为几个小时。下载链接的点击也以同样方式统计。这些数据只以汇总形式查看。请参阅GoatCounter 的隐私政策。

广告：Google AdSense

部分页面展示由 Google AdSense 投放的广告，这有助于支付项目费用。包括 Google 在内的第三方供应商会使用 Cookie，根据你以往对本网站或其他网站的访问来投放广告。Google 使用广告 Cookie，使其及其合作伙伴能够根据你对本网站和/或互联网上其他网站的访问向你投放广告。

如果你位于欧洲经济区、英国或瑞士，在使用个性化广告或广告 Cookie 之前，会通过 Google 的同意提示征求你的同意。你可以随时通过该提示在页面上添加的隐私和 Cookie 设置链接更改你的选择。未经同意，Google 仍可能展示非个性化广告，这类广告仅出于频次控制和防欺诈等目的使用 Cookie。

你可以在Google 广告设置中选择停用个性化广告，或在 aboutads.info 选择停用许多第三方供应商的 Cookie。关于 Google 如何使用展示其广告的网站中的数据，请参阅Google 如何使用来自使用其服务的网站或应用的信息。

托管：GitHub Pages

本网站托管于 GitHub Pages。当你请求页面时，GitHub 可能出于安全和维持服务运行的目的记录你的 IP 地址，详见GitHub 一般隐私声明。下载以及首页上的最新版本查询也由 GitHub 提供。字体由本网站提供，而非来自 Google Fonts。

OriginStack 应用

桌面应用没有账号、没有遥测、没有广告，网站所有者不会从中接收任何数据。它只在进行特定查询时联网，每项查询都直接发送到公共服务：无法识别的目标名称（SIMBAD）、用于星表的视场天球坐标（Gaia、VizieR）、用于查询星历的彗星名称（JPL Horizons），以及向 GitHub 匿名检查是否有新版本。你的图像始终保留在你的电脑上，除非你选择使用自己 API 密钥的 astrometry.net 星图解算器，此时图像会上传到 astrometry.net 进行解算。

README 的网络部分列出了每个请求及其发送的内容。使用 --offline 运行应用，或在应用中勾选“离线”，即可关闭这些查询；设置 ORIGINSTACK_NO_UPDATE_CHECK 即可关闭版本检查。

你的权利

本网站不会要求你提供姓名、电子邮件地址或任何账号，除上述汇总统计外，网站所有者不持有关于你的任何个人数据。根据 GDPR 及类似法律，你可以询问持有哪些关于你的数据，要求更正或删除这些数据，并反对其使用。对于 Google 或 GitHub 持有的数据，请使用上文链接中它们提供的控制选项和联系方式。你也可以向当地的数据保护机构投诉。

如果本政策发生变更，顶部的日期也会随之更新。
