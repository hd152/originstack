Wer diese Website betreibt

originstack.site ist die Website von OriginStack, einem kostenlosen Open-Source-Programm für die Astrofotografie, betrieben von Tom Davenport. Bei Fragen zu dieser Erklärung oder zu Ihren Daten eröffnen Sie ein Issue auf GitHub.

Besuchsstatistiken: GoatCounter

Die Website zählt Besuche mit GoatCounter, um zu sehen, welche Seiten gelesen und welche Downloads genutzt werden. GoatCounter setzt keine Cookies und verfolgt Sie nicht über verschiedene Websites hinweg. Für jeden Seitenaufruf erfasst es die Seite, die verweisende Website, Ihren Browser, Ihr Betriebssystem und Ihre Bildschirmgröße sowie Ihr Land, abgeleitet aus Ihrer IP-Adresse. Ihre IP-Adresse wird nicht gespeichert. Um eindeutige Besuche zu zählen, wird für einige Stunden ein kurzlebiger Hash aufbewahrt. Klicks auf Download-Links werden auf dieselbe Weise gezählt. Die Zahlen werden nur in zusammengefasster Form eingesehen. Siehe die Datenschutzerklärung von GoatCounter.

Werbung: Google AdSense

Einige Seiten zeigen Anzeigen von Google AdSense, die zur Finanzierung des Projekts beitragen. Drittanbieter, einschließlich Google, verwenden Cookies, um Anzeigen auf Grundlage Ihrer früheren Besuche auf dieser Website oder anderen Websites auszuliefern. Durch die Verwendung von Werbe-Cookies können Google und seine Partner Ihnen Anzeigen auf Grundlage Ihrer Besuche auf dieser Website und/oder anderen Websites im Internet ausliefern.

Wenn Sie sich im Europäischen Wirtschaftsraum, im Vereinigten Königreich oder in der Schweiz befinden, werden Sie über die Einwilligungsmeldung von Google um Ihre Einwilligung gebeten, bevor personalisierte Anzeigen oder Werbe-Cookies verwendet werden. Sie können Ihre Wahl jederzeit über den Link zu den Datenschutz- und Cookie-Einstellungen ändern, den diese Meldung der Seite hinzufügt. Ohne Einwilligung kann Google weiterhin nicht personalisierte Anzeigen zeigen, die Cookies nur für Zwecke wie die Begrenzung der Anzeigehäufigkeit und die Betrugsverhinderung verwenden.

Sie können personalisierte Werbung in den Anzeigeneinstellungen von Google deaktivieren oder die Cookies vieler Drittanbieter unter aboutads.info ablehnen. Wie Google Daten von Websites verwendet, die seine Anzeigen zeigen, wird unter Wie Google Informationen von Websites oder Apps verwendet, die unsere Dienste nutzen beschrieben.

Hosting: GitHub Pages

Die Website wird auf GitHub Pages gehostet. GitHub kann Ihre IP-Adresse protokollieren, wenn Sie eine Seite aufrufen, aus Sicherheitsgründen und um den Dienst am Laufen zu halten, wie in der GitHub General Privacy Statement beschrieben. Downloads und die Abfrage der neuesten Version auf der Startseite werden ebenfalls von GitHub bereitgestellt. Die Schriftarten werden von dieser Website ausgeliefert, nicht von Google Fonts.

Die App OriginStack

Die Desktop-App hat kein Konto, keine Telemetrie und keine Werbung, und der Betreiber der Website erhält keine Daten von ihr. Sie geht nur für bestimmte Abfragen online, die jeweils direkt an einen öffentlichen Dienst gesendet werden: einen Objektnamen, den sie nicht kennt (SIMBAD), die Himmelskoordinaten Ihres Bildfelds für Sternkataloge (Gaia, VizieR), den Namen eines Kometen für seine Ephemeriden (JPL Horizons) sowie eine anonyme Prüfung bei GitHub auf eine neuere Version. Ihre Bilder bleiben auf Ihrem Computer, es sei denn, Sie wählen den Plate Solver astrometry.net mit Ihrem eigenen API-Schlüssel; dabei wird das Bild zum Lösen zu astrometry.net hochgeladen.

Der Netzwerkabschnitt der README listet jede Anfrage auf und was sie sendet. Starten Sie die App mit --offline oder kreuzen Sie in der App Offline an, um die Abfragen abzuschalten; setzen Sie ORIGINSTACK_NO_UPDATE_CHECK, um die Versionsprüfung abzuschalten.
