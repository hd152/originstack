Celestron-Origin-Bilder auf dem eigenen Computer stacken

Das Origin stackt laufend während der Aufnahme, bewahrt aber auch jeden aufgenommenen Roh-Frame auf. Wer diese Frames am Computer mit sorgfältiger Kalibrierung und Ausrichtung erneut stackt, erhält ein schärferes und saubereres Bild als das, welches das Teleskop speichert. Diese Anleitung zeigt das mit OriginStack, das kostenlos ist und auf Ihrem eigenen Rechner läuft.

Was in einem Session-Ordner des Celestron Origin liegt

Jede Aufnahmesession erhält einen eigenen Ordner, benannt nach dem Objekt und der Startzeit, zum Beispiel Black_Eye_Galaxy_2026-03-14_21-20-36. Kopieren Sie den ganzen Ordner auf Ihren Computer und lassen Sie seinen Inhalt unverändert. OriginStack erkennt jede Datei selbst.

Die LightsLight0001.fits ...

Eine FITS-Datei pro Belichtung. Das sind die rohen Sensordaten, noch im Farbmosaik der Kamera, und sie werden gestackt.

Kalibrierframesbias, dark, flat

Bias-, Dark- und Flat-Frames, sofern die Session sie enthält. Sie erfassen den Offset des Sensors, sein Wärmesignal und seine Hotpixel sowie die Vignettierung der Optik. OriginStack erstellt daraus Master-Frames und korrigiert damit jedes Light. Eine Session ohne sie lässt sich trotzdem stacken; nur diese Korrektur entfällt.

Session-Informationeninfo.json

Vom Origin geschrieben: der Objektname, das Farbmuster des Sensors, Ihre GPS-Position und wohin am Himmel das Teleskop gerichtet war. OriginStack nutzt sie, um das Objekt zu benennen, passende Einstellungen zu wählen und den Stack am Himmel zu verorten.

Der eigene Stack des TeleskopsFinalStackedMaster.tiff

Das Bild, das das Origin während der Session erstellt hat. OriginStack ignoriert es, damit es nie als weiterer Frame mitgestackt wird.

Stacken, Schritt für Schritt

1. OriginStack installierenWindows, macOS, Linux

Laden Sie unter Windows die Setup-Datei aus dem neuesten Release herunter und führen Sie sie aus. Das Installationsprogramm ist noch nicht code-signiert, daher kann SmartScreen warnen: Wählen Sie „Weitere Informationen“ und dann „Trotzdem ausführen“. Laden Sie auf einem Mac die ZIP-Datei für Apple Silicon oder Intel von derselben Seite herunter und ziehen Sie OriginStack in „Programme“; der erste Start erfordert eine zusätzliche Freigabe, beschrieben zusammen mit den Linux-Schritten auf der Startseite. Kein Konto und kein Python erforderlich.

2. Den Session-Ordner wählen

Öffnen Sie die App und wählen Sie den kopierten Ordner. Sie zählt die Frames und liest den Objektnamen aus der info.json.

3. Angeben, was Sie fotografiert haben

Wählen Sie Galaxie, Nebel, Sternhaufen, Sternfeld oder Komet, oder belassen Sie es bei Automatisch erkennen. Die App schlägt anhand der Session eine Auswahl vor. Wählen Sie Volle Qualität oder für eine schnellere Prüfung Schnellansicht.

4. Auf Start klicken

Die Frames werden kalibriert, bewertet, ausgerichtet (einschließlich der langsamen Bildfeldrotation, die eine azimutale Montierung wie die des Origin erzeugt), mit Ausreißerverwerfung gestackt und fertiggestellt: Gradienten, Farbe und Rauschen werden behandelt, und das Ergebnis wird für die Betrachtung gestreckt. Eine Session mit etwa hundert Frames dauert auf einem aktuellen Desktop-PC mit 8 Kernen ein bis zwei Minuten. Die Vorschau zeigt jeden Schritt, während er läuft.

5. Das Ergebnis verwenden

Lassen Sie die Ausgabe leer, wird der Stack neben dem Session-Ordner gespeichert, ohne je einen früheren zu überschreiben. Sie erhalten ein JPEG zum Ansehen und Teilen und eine FITS-Datei, die linear bleibt, für die Weiterbearbeitung in anderer Software oder um sie später mit einer weiteren Nacht zusammenzuführen.

Lieber die Kommandozeile? Derselbe Lauf lautet python originstack.py -d Black_Eye_Galaxy_2026-03-14_21-20-36 -o black_eye.fits.

Mehrere Nächte auf ein Objekt

Legen Sie die Session-Ordner aller Nächte in einen gemeinsamen übergeordneten Ordner und wählen Sie diesen. Da das Bildfeld des Origin rotiert, während es einem Objekt folgt, passen Nächte selten genau aufeinander. OriginStack liest zuerst die Metadaten jeder Session und fasst dann entweder alle Frames zusammen oder stackt jede Nacht einzeln und verbindet sie mit einem rotationsunabhängigen Sternabgleich, je nachdem, was mehr vom Bild erhält. Um die Frames von heute Nacht zu einem bereits erstellten Stack hinzuzufügen, verwenden Sie --merge. Details finden Sie auf der Seite für Fortgeschrittene.

Warum neu stacken, statt FinalStackedMaster.tiff zu verwenden

Bei vier Origin-Sessions mit denselben Frames waren die Sterne im eigenen Stack des Teleskops 3 bis 38% breiter als bei OriginStack, während das Rauschen innerhalb weniger Prozent lag. Die Datei des Origin hat einen Vorteil: Ihre Himmelsgradienten sind bereits entfernt. OriginStack entfernt sie in seinen Fertigstellungsschritten.

Die vollständigen Messungen, die Methode und ein Vergleich mit Siril und DeepSkyStacker stehen auf der Startseite. Vier Sessions mit einem Teleskop sind eine kleine Stichprobe; tools/bench_vs_origin.py wiederholt den Vergleich mit Ihren eigenen Frames.

Wenn etwas schiefgeht

Es wurden keine Frames gefunden

Wählen Sie den Ordner, der die Light*.fits-Dateien selbst enthält, oder einen Ordner mit Session-Ordnern, nicht einen Ordner darüber.

Es wurde die falsche Objektart gewählt

Wählen Sie die Karte selbst statt Automatisch erkennen. Auf der Kommandozeile übergeben Sie --target-type.

Sie haben keine Internetverbindung

Stacking funktioniert offline. Kreuzen Sie in der App Offline an oder übergeben Sie --offline, und OriginStack stellt keinerlei Netzwerkanfragen.

Alles andere

Eröffnen Sie ein Issue auf GitHub mit dem Log aus dem unteren linken Bereich der App.
