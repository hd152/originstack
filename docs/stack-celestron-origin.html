How to stack Celestron Origin images on your computer

The Origin stacks as it goes, but it also keeps every raw frame it took. Stacking those frames again on a computer, with proper calibration and alignment, gives a sharper and cleaner image than the one the telescope saves. This guide does it with OriginStack, which is free and runs on your own machine.

What is in a Celestron Origin session folder

Each imaging session gets its own folder, named after the target and the start time, for example Black_Eye_Galaxy_2026-03-14_21-20-36. Copy the whole folder to your computer and leave its contents as they are. OriginStack recognises each file by itself.

The light framesLight0001.fits ...

One FITS file per exposure. These are the raw sensor data, still in the camera's colour mosaic, and they are what gets stacked.

Calibration framesbias, dark, flat

Bias, dark and flat frames, when the session has them. They record the sensor's offset, its heat signal and hot pixels, and the optics' vignetting. OriginStack builds master frames from them and corrects every light with them. A session without them still stacks; it just skips that correction.

Session informationinfo.json

Written by the Origin: the target name, the colour pattern of the sensor, your GPS position, and where in the sky the telescope was pointing. OriginStack uses it to name the target, choose settings for it, and place the stack on the sky.

The telescope's own stackFinalStackedMaster.tiff

The image the Origin built during the session. OriginStack ignores it, so it never gets stacked in as another frame.

Stacking it, step by step

1. Install OriginStackWindows, macOS, Linux

On Windows, download the setup file from the latest release and run it. The installer is not code-signed yet, so SmartScreen may warn you: choose More info, then Run anyway. On a Mac, download the Apple silicon or Intel zip from the same page and drag OriginStack into Applications; the first launch needs one extra approval, described with the Linux steps on the home page. It needs no account and no Python.

2. Pick the session folder

Open the app and choose the folder you copied. It counts the frames and reads the target name from info.json.

3. Say what you imaged

Pick Galaxy, Nebula, Star cluster, Star field or Comet, or leave it on Auto-detect. The app suggests one from the session. Choose Full quality, or Quick look for a faster check.

4. Press Start

The frames are calibrated, scored, aligned (including the slow field rotation an alt-az mount like the Origin produces), stacked with outlier rejection, and finished: gradients, colour and noise are handled and the result is stretched for viewing. A session of about a hundred frames takes a minute or two on a recent 8-core desktop. The preview follows each step as it happens.

5. Use the result

Leave the output blank and the stack is saved next to the session folder, never overwriting an earlier one. You get a JPEG to look at and share, and a FITS file that stays linear, for further work in other software or for merging with another night later.

Prefer the command line? The same run is python originstack.py -d Black_Eye_Galaxy_2026-03-14_21-20-36 -o black_eye.fits.

Several nights on one target

Put each night's session folder inside one parent folder and pick the parent. Because the Origin's field rotates as a target tracks, nights rarely line up exactly. OriginStack reads each session's metadata first and either pools all the frames or stacks each night on its own and joins them with a rotation-proof star match, whichever keeps more of the picture. To add tonight's frames to a stack you already made, use --merge. Details are on the advanced page.

Why restack instead of using FinalStackedMaster.tiff

On four Origin sessions, with the same frames, the telescope's own stack had stars 3 to 38% wider than OriginStack's, while noise was within a few percent. The Origin's file does have one advantage: its sky gradients are already removed. OriginStack removes them in its finishing steps.

The full measurements, the method and a comparison with Siril and DeepSkyStacker are on the home page. Four sessions from one telescope are a small sample; tools/bench_vs_origin.py repeats the comparison on your own frames.

If something goes wrong

It found no frames

Pick the folder that holds the Light*.fits files themselves, or a folder of session folders, not a folder above that.

It picked the wrong kind of target

Choose the card yourself instead of Auto-detect. On the command line, pass --target-type.

You have no internet connection

Stacking works offline. Tick Offline in the app, or pass --offline, and OriginStack makes no network requests at all.

Anything else

Open an issue on GitHub with the log from the app's lower-left pane.
