Quién gestiona este sitio

originstack.site es el sitio web de OriginStack, un programa de astrofotografía gratuito y de código abierto, gestionado por Tom Davenport. Para cualquier pregunta sobre esta política o sobre tus datos, abre una incidencia en GitHub.

Estadísticas de visitas: GoatCounter

El sitio cuenta las visitas con GoatCounter para saber qué páginas se leen y qué descargas se usan. GoatCounter no instala cookies ni te rastrea entre sitios. Por cada página vista registra la página, el sitio de procedencia, tu navegador, sistema operativo y tamaño de pantalla, y tu país, obtenido a partir de tu dirección IP. No almacena tu dirección IP. Para contar visitas únicas conserva un hash de corta duración durante unas horas. Los clics en los enlaces de descarga se cuentan de la misma manera. Las cifras solo se ven de forma agregada. Consulta la política de privacidad de GoatCounter.

Publicidad: Google AdSense

Algunas páginas muestran anuncios servidos por Google AdSense, que ayudan a financiar el proyecto. Terceros proveedores, incluido Google, usan cookies para mostrar anuncios basados en tus visitas anteriores a este sitio web o a otros sitios web. El uso de cookies publicitarias por parte de Google le permite a él y a sus socios mostrarte anuncios basados en tus visitas a este sitio y/o a otros sitios de Internet.

Si te encuentras en el Espacio Económico Europeo, el Reino Unido o Suiza, se te pide el consentimiento antes de usar anuncios personalizados o cookies publicitarias, mediante el mensaje de consentimiento de Google. Puedes cambiar tu elección en cualquier momento desde el enlace de configuración de privacidad y cookies que ese mensaje añade a la página. Sin consentimiento, Google puede seguir mostrando anuncios no personalizados, que usan cookies solo con fines como limitar la frecuencia y prevenir el fraude.

Puedes excluirte de la publicidad personalizada en la Configuración de anuncios de Google, o excluirte de las cookies de muchos proveedores externos en aboutads.info. Cómo usa Google los datos de los sitios que muestran sus anuncios se describe en Cómo utiliza Google la información de sitios web o aplicaciones que utilizan sus servicios.

Alojamiento: GitHub Pages

El sitio está alojado en GitHub Pages. GitHub puede registrar tu dirección IP cuando solicitas una página, por seguridad y para mantener el servicio en funcionamiento, tal como se describe en la Declaración general de privacidad de GitHub. Las descargas y la consulta de la última versión en la página de inicio también las sirve GitHub. Las fuentes tipográficas se sirven desde este sitio, no desde Google Fonts.

La aplicación OriginStack

La aplicación de escritorio no tiene cuenta, telemetría ni publicidad, y el propietario del sitio no recibe ningún dato de ella. Solo se conecta a internet para consultas concretas, cada una enviada directamente a un servicio público: un nombre de objeto que no reconoce (SIMBAD), las coordenadas celestes de tu campo para los catálogos de estrellas (Gaia, VizieR), el nombre de un cometa para sus efemérides (JPL Horizons) y una comprobación anónima en GitHub de si hay una versión más reciente. Tus imágenes se quedan en tu ordenador salvo que elijas el resolutor astrométrico de astrometry.net con tu propia clave de API, que sube la imagen a astrometry.net para resolverla.

La sección de red del README enumera cada petición y lo que envía. Ejecuta la aplicación con --offline, o marca Sin conexión en la aplicación, para desactivar las consultas; define ORIGINSTACK_NO_UPDATE_CHECK para desactivar la comprobación de versión.

Tus derechos

Este sitio no pide tu nombre, tu dirección de correo electrónico ni ninguna cuenta, y el propietario del sitio no conserva ningún dato personal sobre ti más allá de las estadísticas agregadas indicadas arriba. En virtud del RGPD y de leyes similares, puedes preguntar qué datos se conservan sobre ti, pedir que se corrijan o eliminen, y oponerte a su uso. Para los datos que conservan Google o GitHub, usa sus controles y contactos enlazados arriba. También puedes presentar una reclamación ante tu autoridad local de protección de datos.

Si esta política cambia, la fecha de la parte superior cambiará con ella.
