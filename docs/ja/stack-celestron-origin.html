Celestron Origin の画像をコンピューターでスタックする方法

Origin は撮影しながらスタックしますが、撮影したすべての生フレームも保存しています。それらのフレームを、適切なキャリブレーションと位置合わせでコンピューター上でスタックし直すと、望遠鏡が保存する画像よりシャープでクリーンな画像が得られます。このガイドでは、無料でお使いのマシン上で動く OriginStack を使ってその手順を説明します。

Celestron Origin のセッションフォルダの中身

撮影セッションごとに、対象名と開始時刻を名前にしたフォルダが作られます（例: Black_Eye_Galaxy_2026-03-14_21-20-36）。フォルダごとコンピューターにコピーし、中身はそのままにしておいてください。OriginStack が各ファイルを自動的に判別します。

ライトフレームLight0001.fits ...

露出ごとに1つの FITS ファイル。カメラのカラーモザイクのままの生のセンサーデータで、これがスタックされます。

キャリブレーションフレームbias, dark, flat

セッションにある場合は、バイアス、ダーク、フラットのフレーム。センサーのオフセット、熱による信号とホットピクセル、光学系の周辺減光を記録したものです。OriginStack はこれらからマスターフレームを作り、すべてのライトフレームを補正します。これらがないセッションもスタックできますが、その補正は省略されます。

セッション情報info.json

Origin が書き込むファイル：対象名、センサーのカラー配列、GPS による位置、望遠鏡が向いていた空の位置。OriginStack はこれを使って対象を特定し、それに合った設定を選び、スタックを天球上に位置付けます。

望遠鏡自身のスタックFinalStackedMaster.tiff

セッション中に Origin が作成した画像。OriginStack はこれを無視するため、フレームの1つとしてスタックされることはありません。

ステップ・バイ・ステップのスタック手順

1. OriginStack をインストールWindows, macOS, Linux

Windows では、最新リリースからセットアップファイルをダウンロードして実行します。インストーラーはまだコード署名されていないため、SmartScreen の警告が出ることがあります。「詳細情報」を選び、「実行」を選んでください。Mac では、同じページから Apple シリコン版または Intel 版の zip をダウンロードし、OriginStack を「アプリケーション」フォルダにドラッグします。初回起動時には追加の許可が1回必要で、その方法はホームページの Linux の手順と並べて説明しています。アカウントも Python も不要です。

2. セッションフォルダを選ぶ

アプリを開き、コピーしたフォルダを選びます。アプリがフレーム数を数え、info.json から対象名を読み取ります。

3. 撮影したものを選ぶ

銀河、星雲、星団、星野、彗星のいずれかを選ぶか、自動検出のままにします。アプリがセッションから1つを提案します。最高品質か、より速く確認できるクイックルックを選んでください。

4. 「開始」を押す

フレームのキャリブレーション、評価、位置合わせ（Origin のような経緯台で生じるゆっくりとした視野回転を含む）、外れ値除外ありのスタック、仕上げが行われます。仕上げではかぶり、色、ノイズを処理し、見やすいように強調します。約 100 フレームのセッションなら、最近の 8 コアのデスクトップ PC で1〜2分です。プレビューは各ステップの進行に合わせて更新されます。

5. 結果を使う

出力を空欄にしておくと、スタックはセッションフォルダの隣に保存され、以前のものを上書きすることはありません。閲覧や共有用の JPEG と、他のソフトでのさらなる処理や後で別の夜と統合するためのリニアのままの FITS ファイルが得られます。

コマンドラインがよい場合は、同じ処理を python originstack.py -d Black_Eye_Galaxy_2026-03-14_21-20-36 -o black_eye.fits で実行できます。

同じ対象を複数の夜に撮影した場合

各夜のセッションフォルダを1つの親フォルダに入れ、その親フォルダを選びます。Origin では対象を追尾するにつれて視野が回転するため、夜ごとの画像がぴったり揃うことはまれです。OriginStack はまず各セッションのメタデータを読み、画像がより多く残る方法を選んで、すべてのフレームをまとめてスタックするか、夜ごとにスタックしてから回転に強い星マッチングで結合します。すでに作ったスタックに今夜のフレームを追加するには --merge を使います。詳しくは上級者向けページをご覧ください。

FinalStackedMaster.tiff を使わずに再スタックする理由

Origin の4つのセッションで同じフレームを使って比べたところ、望遠鏡自身のスタックの星像は OriginStack より 3〜38% 太く、ノイズは数パーセント以内の差でした。Origin のファイルにも利点が1つあり、空のかぶりがすでに除去されています。OriginStack は仕上げの処理でかぶりを除去します。

詳しい測定結果、方法、Siril や DeepSkyStacker との比較はホームページにあります。1台の望遠鏡による4セッションは小さなサンプルです。tools/bench_vs_origin.py で、ご自身のフレームで比較を再現できます。

うまくいかないときは

フレームが見つからない

Light*.fits ファイルそのものが入っているフォルダ、またはセッションフォルダをまとめたフォルダを選んでください。それより上の階層のフォルダではありません。

対象の種類が間違って選ばれた

自動検出ではなく、カードを自分で選んでください。コマンドラインでは --target-type を指定します。

インターネットに接続できない

スタックはオフラインで動作します。アプリで「オフライン」にチェックを入れるか --offline を指定すると、OriginStack はネットワーク接続を一切行いません。

その他の問題

アプリの左下のパネルにあるログを添えて、GitHub で issue を作成してください。
