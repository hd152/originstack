サイトの運営者

originstack.site は、無料でオープンソースの天体写真プログラム OriginStack のウェブサイトで、Tom Davenport が運営しています。このポリシーやあなたのデータに関するご質問は、GitHub で issue を作成してください。

訪問統計：GoatCounter

本サイトは、どのページが読まれ、どのダウンロードが使われているかを把握するため、GoatCounter で訪問数を計測しています。GoatCounter は Cookie を設定せず、サイトをまたいであなたを追跡することもありません。ページビューごとに、ページ、参照元サイト、ブラウザ、オペレーティングシステム、画面サイズ、および IP アドレスから割り出した国を記録します。IP アドレスは保存しません。ユニーク訪問数を数えるため、数時間だけ保持される短期のハッシュを使用します。ダウンロードリンクのクリックも同じ方法で計測されます。数値は集計値としてのみ閲覧されます。GoatCounter のプライバシーポリシーをご覧ください。

広告：Google AdSense

一部のページには Google AdSense による広告が表示され、プロジェクトの運営費用に充てられています。Google を含む第三者配信事業者は Cookie を使用して、本サイトや他のサイトへのユーザーの過去のアクセス情報に基づいて広告を配信します。Google が広告 Cookie を使用することにより、Google とそのパートナーは、本サイトやインターネット上の他のサイトへのアクセス情報に基づいてユーザーに広告を配信できます。

欧州経済領域、英国、スイスにお住まいの場合は、パーソナライズ広告や広告 Cookie が使用される前に、Google の同意メッセージによって同意を求められます。選択内容は、そのメッセージがページに追加するプライバシーと Cookie の設定リンクからいつでも変更できます。同意がない場合でも、Google はパーソナライズされていない広告を表示することがあり、その場合 Cookie は表示頻度の制限や不正防止などの目的にのみ使用されます。

パーソナライズ広告は Google の広告設定でオプトアウトできます。また、aboutads.info で多くの第三者配信事業者の Cookie をオプトアウトできます。Google が広告を表示するサイトのデータをどのように使用するかは、Google のサービスを使用するサイトやアプリから収集した情報の Google による使用に記載されています。

ホスティング：GitHub Pages

本サイトは GitHub Pages でホスティングされています。GitHub は、GitHub General Privacy Statement に記載のとおり、セキュリティとサービス維持のため、ページをリクエストした際の IP アドレスを記録することがあります。ダウンロードと、ホームページでの最新バージョンの照会も GitHub から提供されます。フォントは Google Fonts ではなく本サイトから提供されます。

OriginStack アプリ

デスクトップアプリにはアカウント、テレメトリー、広告はなく、サイト運営者がアプリからデータを受け取ることはありません。アプリがオンラインになるのは特定の照会のときだけで、それぞれ公開サービスに直接送信されます：認識できない対象名（SIMBAD）、恒星カタログ用の視野の天球座標（Gaia、VizieR）、暦表用の彗星名（JPL Horizons）、そして新しいバージョンの有無を確認する GitHub への匿名の問い合わせです。画像はお使いのコンピューターに留まります。ただし、ご自身の API キーで astrometry.net のプレートソルバーを選んだ場合は、解析のため画像が astrometry.net にアップロードされます。

README のネットワークに関するセクションに、各リクエストとその送信内容が記載されています。照会を無効にするには、アプリを --offline 付きで実行するか、アプリで「オフライン」にチェックを入れてください。バージョン確認を無効にするには ORIGINSTACK_NO_UPDATE_CHECK を設定してください。

本サイトは、お名前、メールアドレス、アカウントを求めることはなく、サイト運営者は上記の集計統計以外にあなたに関する個人データを保有していません。GDPR および同様の法律に基づき、あなたは自身について保有されているデータの開示、訂正または削除を求めることができ、その利用に異議を申し立てることができます。Google または GitHub が保有するデータについては、上記リンク先のそれぞれの管理機能や連絡先をご利用ください。また、お住まいの地域のデータ保護機関に苦情を申し立てることもできます。
