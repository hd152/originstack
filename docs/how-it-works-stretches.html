Masked and multiscale raise the mean by about a third over GHS while leaving the sky where it was: the extra brightness all goes to faint structure and faint stars. Noise floor and SETI raise the sky itself.

Which to use

Start with the default

GHS, tuned per target by the advisor. Add --stretch-color preserve if star colours or coloured nebulae matter to you, or use oklab for the same with brighter saturated colours.

Faint stuff is missing

Try masked or multiscale. If you are not sure the faint stuff is really there, look at seti or noisefloor first: they show the noise along with it.

It is cheap to try them all

The stretch is the last step. --from-stack STACK.fits --stretch NAME re-runs only the finishing steps on a stack you already made, with the early steps cached, so each try takes seconds. The FITS file is not affected by any of this: it stays linear.
