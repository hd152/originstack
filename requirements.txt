numpy>=1.20

tqdm>=4.65

# Optional dependencies (install separately as needed):
#
#   Camera RAW support (CR2, CR3, NEF, ARW, DNG, ORF, RW2, RAF, PEF, 3FR, MRW, X3F, IIQ, …):
#     rawpy>=0.19        — read DSLR/mirrorless RAW files as Bayer mosaics
#
#   TIFF input support (16/32-bit linear TIFF lights, e.g. from N.I.N.A./SharpCap/PixInsight):
#     tifffile>=2023.1   — read TIFF images; also used to write --export tiff output
#
#   XISF input (PixInsight's native format) and SER (FireCapture/SharpCap planetary
#   video) support need no extra packages — both are read with a built-in parser.
#
#   astroalign is NOT used anywhere in this codebase -- --merge's cross-night registration
#   (arbitrary field rotation between nights) is src/blind_match.py, native/numpy, no
#   dependency.
#
#   scikit-image and PyWavelets are NOT used anywhere in this codebase (2026-07).
#   Everything that used to need them is native/numpy now, no dependency:
#     - Rigid-transform RANSAC (src/affine_fit.py) and phase cross-correlation
#       (src/phase_correlate.py)
#     - Richardson-Lucy deconvolution CPU fallback (src/psf_deconvolution.py
#       _rl_deconvolve_xp; GPU path already had its own native cupy-FFT path)
#     - Satellite-trail straight-line detection (src/trail_reject.py -- a
#       from-scratch Hough transform + Bresenham line draw, not a bit-exact
#       port of skimage's probabilistic_hough_line, which is itself
#       non-deterministic run-to-run; validated to find the same synthetic
#       trails, and the Bresenham line draw is bit-exact vs skimage.draw.line)
#     - NLM denoising (src/denoising.py _nlm_denoise_numpy -- a faithful
#       reimplementation of the published fast-NLM algorithm skimage's own
#       docstring cites (Darbon 2008), not a bit-exact port: skimage ships
#       fast_mode NLM as a compiled Cython kernel with no .pyx source in the
#       installed wheel. Validated for equivalent denoising behaviour against
#       real skimage -- 0.998 correlation, near-identical background noise
#       reduction on a synthetic test image, see tests/test_nlm_denoise.py)
#     - compute_multiscale_entropy's db4 wavelet decomposition (src/wavelet.py,
#       extended from the bior1.3-only version to also carry db4's filter
#       bank; forward-only, bit-exact vs pywt.wavedec2, see tests/test_wavelet.py)
#     - Wavelet denoising (--denoise, bior1.3) was already native/numpy
#       (src/wavelet.py)
#
#   Denoising:
#     bm3d               — fast BM3D collaborative-filter (--denoise-bm3d); replaces
#                          the built-in pure-scipy DCT fallback (~5-10× faster)
#
#   opencv-python is NOT used anywhere in this codebase. Bilateral filter and Malvar
#   debayer are native Rust kernels (numpy fallback if astro_native isn't built); VNG
#   debayer was removed once it became a pure alias for Malvar.
#
#   Star detection: matched-filter (src/star_detect.py) is the only backend -- no extra
#   package needed. SEP and DAOStarFinder/photutils were both removed from the detection
#   path (2026-07): matched-filter is faster than SEP and at least as accurate on real
#   archive data.
#
#   PSF / deconvolution (--deconvolve rl): parametric Moffat/Gaussian fitting via
#   scipy.optimize.curve_fit, no extra package needed. photutils.psf.EPSFBuilder (empirical
#   PSF) was removed (2026-07) along with its dependency.
#
#   GPU acceleration:
#     cupy-cudaXXx       — GPU acceleration (--use-gpu); see requirements-gpu.txt
#
#   Desktop app (python desktop_app.py):
#     pywebview>=5.0     — native window wrapping src/webview.py's dashboard server;
#                          without it, run with --web-view and open the URL in a
#                          browser instead -- the dashboard/Setup form work identically
#
#   astroquery is NOT used anywhere in this codebase (2026-07). Every network
#   catalogue/service lookup it used to provide is direct HTTP now
#   (src/net_query.py, stdlib urllib, no dependency):
#     - astrometry.net plate solving (--plate-solve): upload/poll/fetch-WCS
#       against nova.astrometry.net's REST API
#     - Gaia DR3 (--color-calibrate) and VizieR 2MASS
#       fallback (color/photometric calibration): IVOA TAP queries
#     - SIMBAD (plate-solve object ID, target-name inference): IVOA TAP
#       queries
#     - JPL Horizons (--comet-designation ephemeris tracking): the modern
#       ssd.jpl.nasa.gov REST ephemeris API
