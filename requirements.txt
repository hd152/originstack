# Optional dependencies (install separately as needed):
#
#   Camera RAW support (CR2, CR3, NEF, ARW, DNG, ORF, RW2, RAF, PEF, 3FR, MRW, X3F, IIQ, …):
#     rawpy>=0.19        — read DSLR/mirrorless RAW files as Bayer mosaics
#
#   TIFF input support (16/32-bit linear TIFF lights, e.g. from N.I.N.A./SharpCap/PixInsight):
#     tifffile>=2023.1   — read TIFF images; also used to write --export tiff output
#
#   XISF input (PixInsight's native format) and SER (FireCapture/SharpCap planetary
#   video) support need no extra packages — both are read with a built-in parser.
#
#   Improved registration:
#     astroalign         — triangle-pattern star matching; fallback when RANSAC fails
#     scikit-image       — sub-pixel phase cross-correlation refinement (registration.py,
#                          debayer.py), NLM denoising, Richardson-Lucy deconvolution,
#                          preview stretch (exposure), satellite-trail Hough detection.
#                          Rigid-transform RANSAC fitting no longer needs it (native Rust
#                          kernel in src/affine_fit.py) -- every remaining use degrades
#                          gracefully when absent
#
#   Denoising:
#     bm3d               — fast BM3D collaborative-filter (--denoise-bm3d); replaces
#                          the built-in pure-scipy DCT fallback (~5-10× faster)
#     PyWavelets         — wavelet denoising (--denoise)
#
#   opencv-python is NOT used anywhere in this codebase. Bilateral filter and Malvar
#   debayer are native Rust kernels (numpy fallback if astro_native isn't built); VNG
#   debayer aliases to Malvar; NLM denoising uses skimage.restoration.denoise_nl_means.
#
#   Background extraction:
#     graxpert           — AI-powered gradient removal via Python API (--bg-method graxpert);
#                          if not installed falls back to the GraXpert CLI subprocess
#
#   Star detection (--star-detector):
#     sep                — optional secondary backend (SourceExtractor C library); the
#                          default (matched-filter, src/star_detect.py) needs no extra
#                          package and is faster than sep on real data (~1.7-2.1x) --
#                          see --star-detector help. DAOStarFinder/photutils is no
#                          longer used for detection at all.
#
#   PSF / deconvolution:
#     photutils          — photutils.psf.EPSFBuilder for empirical PSF estimation
#                          (--deconvolve rl); falls back to parametric Moffat/Gaussian
#                          fitting when not installed
#
#   GPU acceleration:
#     cupy-cudaXXx       — GPU acceleration (--use-gpu); see requirements-gpu.txt
#
#   Plate solving:
#     astroquery         — astrometry.net plate solving (--plate-solve);
#                          see requirements-astrometry.txt
